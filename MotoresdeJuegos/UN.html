¿Qué es Unreal Engine?
Unreal Engine es un motor gráfico de alto rendimiento desarrollado por Epic Games, diseñado para crear videojuegos 3D, simulaciones y contenido audiovisual fotorrealista en tiempo real. Es ampliamente utilizado en la industria triple A (Fortnite, Hogwarts Legacy) y en cine, permitiendo crear iluminación avanzada y físicas complejas sin necesidad de programación compleja gracias a su sistema Blueprints.

¿Qué lenguajes usa?
Unreal Engine utiliza principalmente C++ para programación de alto rendimiento y lógica compleja, y Blueprints Visual Scripting, un sistema de nodos visuales para diseñar lógica sin escribir código. Además, se puede usar Python para automatizar tareas en el editor y Verse para el desarrollo en el metaverso (UEFN).
